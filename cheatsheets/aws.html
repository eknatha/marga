AWS cheat sheet

Identity, networking, compute, storage, cost and incident-response commands for AWS.

In the print dialog, choose "Save as PDF" as the destination.

Identity and CLI

aws sts get-caller-identity
aws configure list
aws iam list-attached-role-policies --role-name shop-api-role
aws iam simulate-principal-policy \
  --policy-source-arn arn:aws:iam::123456789012:role/shop-api-role \
  --action-names s3:GetObject \
  --resource-arns arn:aws:s3:::acme-uploads/shop/logo.png
aws iam generate-credential-report

Use roles and temporary credentials. Deny beats allow. Check who you are before debugging what you may do.

Policy skeleton

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::acme-uploads/shop/*"
    }
  ]
}

Cost

  --time-period Start=2026-10-01,End=2026-10-24 \
  --granularity DAILY --metrics UnblendedCost \
  --group-by Type=DIMENSION,Key=SERVICE

Tags owner, env, service
Right-size Use measured utilization

Clean up Unattached volumes, old snapshots, idle load balancers

Compromised key response

  1. Deactivate the access key
  2. Review CloudTrail for what it did, including other regions
  3. Terminate unknown resources and revoke sessions
  4. Rotate related credentials
  5. Replace the key with a role

Danger

aws s3 sync --delete and aws s3 rm --recursive remove objects at once, and on a versioned bucket they leave delete markers. Run --dryrun first.

Danger

aws ec2 terminate-instances cannot be undone, and attached volumes with DeleteOnTermination are removed. Take a snapshot and use stop-instances when you are unsure.

Warning

Opening a security group to 0.0.0.0/0 on SSH or database ports exposes it to the whole internet. Use your own address range or Session Manager.

Cost and safety checks

aws ce get-cost-and-usage --time-period Start=2026-10-01,End=2026-10-24 --granularity DAILY --metrics UnblendedCost
aws budgets describe-budgets --account-id 123456789012
aws ec2 describe-addresses --query 'Addresses[?AssociationId==null]'
aws ec2 describe-nat-gateways --filter Name=state,Values=available
aws cloudtrail lookup-events --lookup-attributes AttributeKey=EventName,AttributeValue=DeleteBucket --max-results 5
aws configservice describe-compliance-by-config-rule
Warning

Unattached Elastic IPs, idle NAT gateways, old snapshots and unused load balancers keep costing money. Review them every month, and set a budget alert.

Warning

Check aws sts get-caller-identity and AWS_PROFILE before every change. Running a command in the wrong account is a frequent cause of incidents.

Warning

Do not put access keys in scripts or environment files in a repository. Use roles, SSO (aws sso login) or a secrets manager, and rotate any key that was exposed.

Danger

aws iam delete-user, delete-role and delete-policy can break running workloads that use them. Search CloudTrail and Access Advisor for recent use first.
